How to read them

          

            
Noul
One independent P(yes) per statement. They don't have to add up; your code combines them. Best for facts you'll weigh yourself, like this game does.

            
Choice
Picks one option. Probabilities across options sum to 1, and you get a confidence. Best for routing and classification.

            
Score
Rates on ordered levels. The score is a probability-weighted average, so it can fall between levels (1.8 = mostly level 2). Also has a confidence.

            
Probability vs confidence
Probability says which answer. Confidence is computed from how peaked the spread is: a flat spread means "I'm not sure", so your code can act, double-check, or hand off.
